========================================================================
  ชุดติดตั้งและสั่งการเครื่องพิมพ์ RISO ORPHIS FW1230 (1-Click & CLI Controller)
  St. Mary School Campus Network (IP: 172.16.40.194)
========================================================================

📁 ไฟล์และโฟลเดอร์หลัก:
1. [ Install_RISO.bat ]   <--- ดับเบิ้ลคลิกเพื่อติดตั้งไดรเวอร์ + โคลนการตั้งค่าทันที
2. [ riso.bat ]           <--- เครื่องมือสั่งการและสั่งพิมพ์ผ่าน Command Line (CLI)
3. [ Uninstall_RISO.bat ] <--- ดับเบิ้ลคลิกเพื่อถอนการติดตั้งเครื่องพิมพ์ออกจากระบบ
4. [ riso_settings.dat ]  <--- ค่าคอนฟิกแม่แบบ (DevMode: A4, 2-Sided Duplex, ถาดกระดาษ ฯลฯ)
5. [ Driver/ ]            <--- โฟลเดอร์ไดรเวอร์แท้ 64-bit (RISODRV.INF)

------------------------------------------------------------------------
1. วิธีติดตั้งแบบปกติ (Double-Click):
------------------------------------------------------------------------
- ดับเบิ้ลคลิกไฟล์ "Install_RISO.bat" แล้วกด "Yes" (UAC) ระบบจะลงให้จนเสร็จ

------------------------------------------------------------------------
2. วิธีสั่งการผ่าน Command Line (CLI):
------------------------------------------------------------------------
เปิด Command Prompt หรือ PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่ง:

  • riso ping
    -> ทดสอบ Ping ไปยัง 172.16.40.194 และเช็คพอร์ต 9100 (RAW) ว่าพร้อมพิมพ์หรือไม่

  • riso check  (หรือ riso status)
    -> เช็คสถานะการเชื่อมต่อ และสถานะเครื่องพิมพ์ใน Windows Spooler

  • riso test
    -> ตรวจสอบการเชื่อมต่ออัตโนมัติ ถ้า Ping เจอ จะสั่งพิมพ์หน้าทดสอบ (Windows Test Page) ทันที!

  • riso print "D:\ข้อสอบ.pdf"
    -> สั่งพิมพ์ไฟล์เอกสาร (PDF, Word, TXT, รูปภาพ) ออกเครื่องพิมพ์ RISO ทันที

  • riso queue  (หรือ riso jobs)
    -> ดูคิวงานพิมพ์ที่กำลังค้างอยู่

  • riso clear
    -> ล้างและยกเลิกคิวงานพิมพ์ที่ค้างอยู่ทั้งหมด

  • riso default
    -> ตั้งค่า RISO เป็นเครื่องพิมพ์เริ่มต้น (Default Printer)

  • riso install
    -> สั่งติดตั้งไดรเวอร์และตั้งค่าผ่าน Command line อัตโนมัติ (Silent 100%)
